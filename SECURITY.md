# 🔒 Security Policy

## Supported Versions

Security fixes and updates are applied to the latest release on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

---

## 🛡️ Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please do **NOT** open a public issue.

Instead, please send an email to **esawi@ieee.org** with:
- A description of the vulnerability.
- Steps or proof of concept to reproduce the issue.
- Potential impact.

We will acknowledge receipt of your report within 48 hours and work on a fix promptly.
